# Menu API

A simple backend API for managing menu items.

## Features

- List menu items
- Retrieve a menu item by ID
- Create, update, and delete menu items

## Getting Started

Install dependencies and start the development server using the commands configured by the project:

```bash
npm install
npm run dev
```

The API is then available at the local URL shown in the terminal.

## Example Menu Item

```json
{
	"name": "Classic Burger",
	"description": "Beef burger with lettuce, tomato, and cheese.",
	"price": 9.99,
	"category": "Main"
}
```
